msm-manage-app プライバシーポリシー

msm-manage-app は、個人が自宅内での利用のために開発・運用している非公開の個人用ポータルアプリケーションです。

収集する情報

本アプリケーションは、Google Drive API (drive.file スコープ) を利用し、本アプリケーションが作成したファイル・フォルダ(楽天カード利用明細のCSV、YouTubeダウンロードファイル等)を、開発者本人のGoogle Driveアカウントへアップロードする目的でのみアクセスします。

情報の利用目的

取得したアクセス権は、開発者本人が作成したファイルを開発者本人のGoogle Driveへ保存する用途にのみ使用します。

第三者への提供

取得した情報を第三者に提供・共有することはありません。

お問い合わせ

本アプリケーションに関するお問い合わせは、開発者本人までご連絡ください。
